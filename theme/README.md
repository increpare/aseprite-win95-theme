# Windows 95 theme

Select **Windows 95** in **Edit > Preferences > Theme** after installation.
Reselect it or restart Aseprite after an update.

Gray panels and tabs, navy captions and selections, crisp beveled controls,
and white recessed fields. Uses installed Tahoma with Aseprite's font as fallback.

Derived from Aseprite's default theme by David Capello and Ilija Melentijevic,
with contributions by Nicolas Desilets. Adapted colors, control borders and
states, typography, and spacing. Licensed CC BY 4.0; see LICENSE.txt.
